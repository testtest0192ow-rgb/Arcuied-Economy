# ARCUEID PRIME

Discord economy bot built with discord.js v14, MongoDB and Canvas.

## Required environment
- `DISCORD_TOKEN` (or `BOT_TOKEN`/`TOKEN`)
- `MONGO_URI` (or `MONGODB_URI`/`MONGO_URL`)
- `CLIENT_ID` (or `DISCORD_CLIENT_ID`/`APPLICATION_ID`/`DISCORD_APPLICATION_ID`)

Optional:
- `TEST_GUILD_ID` for fast guild command deployment
- `BOT_OWNER_ID`

## Local
```bash
npm install
npm run check
npm run deploy
npm start
```

Render build: `npm install`
Render start: `npm start`
