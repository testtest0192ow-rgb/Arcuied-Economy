# Application Emoji — авто-загрузка

Положи сюда PNG/GIF/WebP/JPEG-файлы (до 256 КБ каждый, требование самого Discord) —
имя файла без расширения станет именем эмодзи. Например:

```
assets/emoji/coin.png
assets/emoji/donatecoin.png
```

Дальше:

```bash
npm run upload-app-emoji
```

Скрипт зальёт их через API как **Application Emoji** — они станут доступны боту
сразу на всех серверах, без привязки к конкретной гильдии. В конце выведет готовые
строки вида `<:coin:1234567890>` — их можно сразу вставлять в `src/utils/embeds.js`
(`COIN_ICON`, `DONATE_ICON`) или куда угодно ещё.

**Важно:** используй только те изображения, на которые у тебя есть права — свои,
куплены, с открытой лицензией. Не перезаливай чужой арт с других серверов/ботов —
это создаёт ту же проблему копирования, только в другом месте.

Имя эмодзи должно быть 2-32 символа, только латиница/цифры/underscore — скрипт сам
почистит недопустимые символы из имени файла, но лучше сразу называть файлы
аккуратно (`coin.png`, не `монета (1).png`).
