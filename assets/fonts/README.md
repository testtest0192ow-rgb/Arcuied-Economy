# Шрифты для Canvas-профиля

Сюда нужно положить .ttf-шрифт, который поддерживает кириллицу — без него русский
текст на карточке профиля может отрисоваться "тофу"-квадратиками на некоторых
серверных окружениях (у Render в базовом образе не всегда есть шрифты с кириллицей).

Код (`src/services/ProfileCardService.js`) сам подхватит шрифт, если файлы здесь
появятся — ничего в коде менять не нужно, только положить файлы с такими именами:

- `Inter-Bold.ttf`
- `Inter-Regular.ttf`

Рекомендую шрифт **Inter** (бесплатный, с кириллицей, часто используется в
premium-интерфейсах) — скачать можно с https://fonts.google.com/specimen/Inter
(Google Fonts, раздел "Download family", там будут файлы `Inter-Bold.ttf` и
`Inter-Regular.ttf` в папке static). Подойдёт и любой другой шрифт с кириллицей
(Manrope, Montserrat, Noto Sans) — просто переименуй файлы под эти два имени, либо
поправь пути в `ProfileCardService.js`.

Если файлов здесь нет — карточка всё равно отрисуется (на системном шрифте по
умолчанию), просто кириллица может выглядеть криво в зависимости от окружения.
Это не критично для работы бота, только для внешнего вида.
